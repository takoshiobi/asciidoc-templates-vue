=== Message Contract
==== Example
[source,json]
----

  "event_id": "evt_550e8400-e29b-41d4-a716-446655440001",
  "event_type": "ORDER_PAID",
  "event_version": 1,
  "produced_at": "2026-04-06T10:30:00Z",
  "source_service": "order-service",
  "correlation_id": "req_123e4567-e89b-12d3-a456-426614174001",
  "payload": {
    "order_id": "ord_12345",
    "customer_id": "cus_67890123",
    "amount": 99.99,
    "currency": "USD",

  }

----

==== Message Fields Description
[cols="1,1,1,2", options="header"]
|===
| Field | Type | Required | Description
| `event_id` | string (UUID) | Yes | Unique message ID (idempotency for consumers)
| `event_type` | string (enum) | Yes | Type of business event (see table below)
| `event_version` | int | Yes | Schema version (increment on breaking changes)
| `produced_at` | string (ISO 8601) | Yes | When our service produced this message (UTC)
| `source_service` | string | Yes | Always `{our.service.name}` for this topic
| `correlation_id` | string (UUID) | Yes | End-to-end trace ID (from original HTTP/gRPC request)
| `payload.order_id` | string | Yes | Order identifier (core business key)
| `payload.customer_id` | string | Yes | Customer identifier
| `payload.amount` | decimal | Conditional* | Monetary amount (for payment-related events)
| `payload.currency` | string (ISO 4217) | Conditional* | Currency code: `USD`, `EUR`, `GBP`
| `payload.paid_at` | string (ISO 8601) | Conditional* | When payment occurred (for `ORDER_PAID`)
| `payload.shipped_at` | string (ISO 8601) | Conditional* | When order shipped (for `ORDER_SHIPPED`)
| `payload.cancel_reason` | string | Conditional* | Why order cancelled (for `ORDER_CANCELLED`)
| `payload.failure_reason` | string | Conditional* | Why payment failed (for `PAYMENT_FAILED`)
|===

=== Trigger Conditions
Our service sends a message to this topic when:

. **Order is created** — After successful `POST /orders` or `rpc CreateOrder`
. **Order status changes** — Status transitions: `AWAITING_PAYMENT` → `PAID` → `SHIPPED` → `DELIVERED`
. **Order is cancelled** — By customer or admin
. **Payment is refunded** — After successful refund processing
. **Payment fails** — After 3 failed payment attempts

=== Topic Configuration 
[cols="1,2,2", options="header"]
|===
| Property | Value | Explanation
| Partitions | `6` | Matches expected throughput; can be increased if needed
| Replication factor | `3` | Fault tolerance (minISR=2)
| Retention period | `7 days` | Messages deleted after 7 days
| Max message size | `1 MB` | Larger messages rejected
|===
